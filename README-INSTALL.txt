TAYASSUK OS — BLACK BIRDS + BLUE/ORANGE FLECKS

This update keeps the existing blue and soft orange flecks and uses BLACK bird silhouettes.

INSTALL:
1. Back up your current styles.css and index.html.
2. Replace styles.css with the included styles.css.
3. Copy birds.js into the same folder as index.html.
4. In index.html, add this immediately before </body>:
   <script src="birds.js" defer></script>
5. Commit/push to GitHub Pages, then hard-refresh with Ctrl + Shift + R.

Birds are small distant black silhouettes with gentle wing flaps. The animation uses a single SVG overlay and transform motion.
